# 🚀 VocabMin Companion (Chrome 擴充功能)

專為**英文閱讀與 PDF 文件**量身打造的 Chrome 擴充功能（Manifest V3），將 VocabMin 的即時查詞、發音、長難句 AI 語法拆解與「一鍵收錄生字」超能力無縫帶入您的 Chrome 瀏覽器！

---

## ✨ 核心特色

1. **📄 PDF 與網頁隨選即查**：
   - 瀏覽英文 PDF 或一般網頁時，選取任何單字即可看見浮動 **✨ 查單字** 按鈕。
   - 支援滑鼠右鍵選單：**「🔍 用 VocabMin 查詢單字」** 或 **「🧠 AI 語法結構解析」**（在 PDF 嵌入檢視器中 100% 穩定支援！）。
2. **🔊 美式標準真人發音**：
   - 內建 Web Speech API 語音合成，點擊小喇叭即刻朗讀，支援 IPA 音標標註。
3. **🧠 AI 長難句結構剖析**：
   - 即時拆解主詞、謂語動詞、子句關係、分詞構句與修飾語，附帶高品質繁體中文翻譯與重點學習提示。
4. **⭐ 一鍵收錄至 VocabMin 單字庫**：
   - 點擊「收錄至 VocabMin」，自動保留生字、釋義、例句與原始文章語境上下文。
   - 支援一鍵將生字同步進已開啟的 VocabMin 學習中心網頁。
5. **🛡️ 零干擾 Shadow DOM 架構**：
   - 介面完全封裝於 Shadow DOM，絕對不破壞閱讀頁面的原始 CSS 排版，亦可自由拖曳調整視窗位置。
6. **🌐 離線彈性線路**：
   - 支援連接雲端伺服器（預設 `https://vocabmin.ai.studio`）或本地開發端點；若離線時自動啟用 Google Translate 與開放雙語辭典備援，永遠不報錯中斷閱讀。

## 🛠️ 安裝教學（30 秒完成）

### 步驟 1：開啟 Chrome 擴充功能管理頁面
1. 在 Chrome 網址列輸入：
   ```text
   chrome://extensions/
   ```
2. 開啟右上角的 **「開發人員模式 (Developer mode)」** 開關。

### 步驟 2：載入擴充功能
1. 點擊左上角的 **「載入未封裝項目 (Load unpacked)」** 按鈕。
2. 選擇本專案中的 `extension` 資料夾：
   ```text
   c:\Users\user\Desktop\Apps\vocabmin\extension
   ```
3. 成功載入！您會在擴充功能清單中看到 **「VocabMin Companion - 智慧英文閱讀與單字隨選助手」**。

## 📑 閱讀本地 PDF 檔案特別設定（關鍵！）

若您想在 Chrome 中開啟電腦本機的 PDF 檔案（例如 `file:///C:/Users/.../paper.pdf`）並使用查詞功能：

1. 在 `chrome://extensions/` 頁面找到 **VocabMin Companion**。
2. 點擊 **「詳細資訊 (Details)」**。
3. 向下捲動並開啟 **「允許存取檔案網址 (Allow access to file URLs)」**。
4. 將您的 PDF 檔案直接拖進 Chrome 瀏覽器分頁中，即可開始劃詞查單字！

## 💡 使用小技巧

- **查單字**：在任何網頁或 PDF 選取單字，點擊浮現的「查單字」標籤或按滑鼠右鍵。
- **解析長難句**：選取一整個句子，點擊浮動標籤或右鍵選單「🧠 AI 語法結構解析」，切換至「AI 句型解析」分頁。
- **拖曳移動**：點住彈出卡片的頂部即可隨意拖曳，避免擋住下方的閱讀文字。
- **同步單字**：點擊瀏覽器工具列上的 VocabMin Companion 圖示，切換到「最近生字」，點擊「🔄 同步到網頁」，即可將在 PDF 讀到的所有生字一次傳送到 VocabMin 複習中心！
